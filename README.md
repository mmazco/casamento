# Casamento em Lisboa

Maryam and Gabriel’s responsive wedding invitation, inspired by Portuguese azulejo tiles.

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 4173
```

Visit http://localhost:4173.

Hover over the highlighted snail tile, or tap it on mobile, to reveal the ceremony at Café des Épices at 16:00 Lisbon local time. The RSVP dialog is currently a placeholder and does not collect responses.

The site uses Google Fonts with local font fallbacks. Original artwork by [@dacostaworld](https://www.instagram.com/dacostaworld), adapted for this invitation.
