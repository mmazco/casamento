# Casamento em Lisboa

Maryam and Gabriel’s responsive wedding invitation, inspired by Portuguese azulejo tiles.

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 4173
```

Visit http://localhost:4173.

Hover over the highlighted four-tile café panel, or tap it on mobile, to reveal the ceremony at Café des Épices at 16:00 Lisboa local time. The next four-tile panel shows Fábrica Braço de Prata and the river, and flips to dinner and party details from 18:00 Lisboa local time. The RSVP dialog is currently a placeholder and does not collect responses.

The bottom two tiles show a Santa Cruz getaway preview. Guest-specific access is not implemented yet. Venue names on the reverse faces link to Google Maps. Yellow outlines indicate the interactive panels.

The site uses Google Fonts with local font fallbacks. Original artwork by [@dacostaworld](https://www.instagram.com/dacostaworld), adapted for this invitation.
